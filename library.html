03 · 常用组件 UI Components

常用组件

01 · 模态框

Modal

覆盖页面，先处理再走
覆盖在当前页上的对话框，背景被遮罩，打开时焦点移到输入框，关闭后焦点返回触发按钮，Esc 关闭。
可复制的 PROMPT
浩然网站点击 Contact 后打开 Modal，Modal 内包含姓名、邮箱、项目类型和留言；打开时把键盘焦点移动到标题或第一个输入框，关闭后把焦点返回触发按钮；使用原生 dialog 和 showModal()，支持 Esc 关闭，并阻止背景内容被键盘访问。
